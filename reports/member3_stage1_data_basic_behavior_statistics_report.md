# Member 3 基于清洗表的基础行为统计与 EDA 数据准备报告

## 1. 数据说明

- 正式输入：`data/processed/user_behavior_clean.parquet`
- 数据规模：12,256,906 条行为记录
- 时间范围：2025-11-18 00:00:00 至 2025-12-18 23:00:00
- 统计实现：`src/data/basic_analysis.py` 和 `sql/basic_analysis/basic_behavior_statistics.sql`
- 输出目录：`data/interim/`
- 输出文件：`behavior_distribution.csv`、`behavior_statistics.csv`、`item_statistics.csv`、`top_10_item.csv`、`category_statistics.csv`、`top_10_category.csv`、`daily_behavior.csv`、`hourly_behavior.csv`、`behavior_hourly_distribution.csv`、`descriptive_funnel.csv`

本报告仅使用当前正式 clean 数据及其重新生成的 EDA 表。旧版 6,213,379 行统计结果不再使用。

## 2. 四类行为分布

输出：`data/interim/behavior_distribution.csv`

| 行为 | 行为次数 | 占比 |
| --- | ---: | ---: |
| 浏览（pv） | 11,550,581 | 94.24% |
| 收藏（fav） | 242,556 | 1.98% |
| 加购（cart） | 343,564 | 2.80% |
| 购买（buy） | 120,205 | 0.98% |
| 合计 | 12,256,906 | 100.00% |

浏览行为占全部行为的 94.24%，明显高于收藏、加购和购买。购买行为占比为 0.98%，说明从流量行为到购买行为存在明显数量递减。该占比是行为记录占比，不是用户转化概率。

## 3. 用户行为统计

输出：`data/interim/behavior_statistics.csv`

| 总行为次数 | 购买次数 | 购买用户数 | 未购买用户数 | 复购用户数 |
| ---: | ---: | ---: | ---: | ---: |
| 12,256,906 | 120,205 | 8,886 | 1,114 | 8,148 |

统一定义：

- 购买用户：至少存在 1 条 `buy` 行为的用户。
- 未购买用户：统计窗口内存在行为，但没有 `buy` 行为的用户。
- 复购用户：至少存在 2 条 `buy` 行为的用户。由于数据中没有订单 ID，该指标仅代表购买行为记录不少于 2 条，不代表两张独立订单。

当前 10,000 名用户中有 8,886 名产生过购买行为，其中 8,148 名用户至少存在两条购买记录；另有 1,114 名用户在观察窗口内没有购买行为。

## 7. 描述性转化漏斗

输出：`data/interim/descriptive_funnel.csv`

| 阶段 | 行为次数 | 相对浏览次数比例 |
| --- | ---: | ---: |
| 浏览（PV） | 11,550,581 | 100.00% |
| 收藏（Favorite） | 242,556 | 2.10% |
| 加购（Cart） | 343,564 | 2.97% |
| 购买（Purchase） | 120,205 | 1.04% |

该漏斗按四类行为记录数进行描述。收藏、加购和购买分别相当于浏览行为量的 2.10%、2.97% 和 1.04%。这些数值不是去重用户转化率，也不代表所有用户严格按照“浏览—收藏—加购—购买”的顺序完成转化。
